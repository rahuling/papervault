Private by design

Your documents are often the most sensitive things on your computer. PaperVault treats them that way.

No uploads

Files are read and written on your machine. There is no PaperVault server to send them to.

No accounts or tracking

Nothing to sign up for, and no analytics. The app makes no network requests.

Local-only interface

The browser UI listens on 127.0.0.1, so other devices on your network cannot reach it. Requests with unexpected hostnames are rejected.

Open source

The code is public on GitHub. You can read exactly what it does with your files.

Install

Build PaperVault from source with Rust 1.85 or newer. Then start the app and open it in your browser.

PDF to images needs Poppler's pdftoppm on your PATH. Every other tool works without extra software.

git clone https://github.com/rahuling/papervault
cd papervault
cargo install --path .

papervault serve        # opens http://127.0.0.1:8844
papervault tools        # list every command-line tool
