PDF tools that never leave your computer.

Merge, split, compress, watermark and convert PDFs. Your files are processed on your own machine. Nothing is uploaded, and there are no accounts or trackers.

Install PaperVault View source
Open source · MIT · Written in Rust

What it does

Merge PDFs

Join several files into one, in the order you choose.

Split PDF

Cut a PDF by page ranges, or every N pages.

Extract and delete pages

Keep or remove the pages you pick, in any order.

Reorder and rotate

Rearrange pages, and turn them 90, 180 or 270 degrees.

Crop margins

Trim white space from every page.

Compress PDF

Shrink large scanned or photo-heavy files by downscaling images.

Watermark

Stamp text such as DRAFT or CONFIDENTIAL across pages.

Page numbers

Add numbers or header and footer text anywhere on the page.

Images to PDF

Turn photos into a PDF with fit, A4 or Letter pages.

PDF to images

Save each page as PNG or JPG.

Extract text and images

Copy the text out of a PDF, or save the pictures inside it.

Properties and info

Set the title and author, and see page count and details.

Private by design

  • No uploads. PaperVault has no network code for your files. Every operation runs on your computer.
  • No accounts, no analytics, no tracking. The app does not phone home.
  • Local-only web UI. The browser interface runs on 127.0.0.1, so other devices on your network cannot reach it. It also rejects requests from unexpected hostnames.
  • Open source. The code is on GitHub, so you can check these claims yourself.

Install

PaperVault is built from source with Rust (1.85 or newer):

git clone https://github.com/rahuling/papervault
cd papervault
cargo install --path .
papervault serve      # opens the UI at http://127.0.0.1:8844

PDF to images needs Poppler's pdftoppm on your PATH. Every other tool works without extra software.

Command line and AI assistants

Every tool is available from the terminal, with JSON output for scripts and AI assistants:

papervault tools
papervault run merge a.pdf b.pdf -o out/
papervault run split big.pdf -p every=10 -o parts/
papervault run compress scan.pdf -p quality=60 -o out/
papervault --json run to-text invoice.pdf -o out/

An AI skill file ships with the project in skills/papervault, so assistants can run PaperVault for you without sending your files to a cloud service.
